# wikiml-labs

Code for the classroom labs on the Machine Learning wiki:
[https://ml.albertprofe.dev](https://ml.albertprofe.dev)

Each folder is one lab. Open the notebook in Colab, or run the `.py` script locally:

```bash
pip install -r requirements.txt
```

The written walkthroughs live on the wiki, under Foundations → Labs.

## Taxi Lab

Branch `taxi-lab` (switch the Colab and GitHub links to `main` or `master` after this branch is merged).
